The pattern behind four of the five P0s is one thing: **the embedded development database connects as
a superuser, and a superuser does not see row-level security.** Tests, local journeys and the
development server all ran on the one path production never takes. FR-008's fix closes that for
request handling; `packages/db` now has tests that `SET ROLE govintel_app` for whole flows.

## 5. What is dead, placeholder or disconnected

From the inventory, then checked by hand:

- **Fabricated Project Home.** `/p/[projectId]` rendered a made-up project for any id with no access
  check. Replaced by a real Project Home; the sample moved to `/design/reference`, which 404s in
  production.
- **Navigation to nowhere.** `apps/web/src/components/shell/navigation.ts` lists 19 distinct routes
  that do not exist. Its only consumer is now the design reference. Recorded (register W-UI-3).
- **Modules without a direct production caller** (31, some reached transitively): notably
  `@govintel/discovery/*` (search, palette, notifications), `@govintel/db/{rbac,authorize,tenancy}`,
  `@govintel/governance/document`, `@govintel/completion/archive`, `@govintel/organization/membership`,
  `@govintel/resilience/outbox`, `@govintel/rules/methodology`. Listed in the inventory's
  `modulesWithoutProductionCallers`.
- **Tables never written by production code:** `project_members`, `twin_changes`, `twin_baselines`,
  `twin_calculations`; `outbox_events` has no producer.
- **Tenant data without row-level security:** `intake_answers`, `ai_imports` (writers also leave
  `organization_id` unset). Guarded by application-level ownership checks only.
- **Hard-coded inputs presented as results:** `/plan/[id]/close` (failing tests, security findings,
  stale documents all `0`), `/plan/[id]/release` (every input `[]`), `/plan/[id]/budget` (£500/day,
  `UNKNOWN` complexity, `resources: []`), methodology fixed to `AGILE`.
- **Feedback that never reaches the user:** several actions redirect with `?error=`, `?requested=`,
  `?decided=`, `?applied=` to pages that do not read them.
- **Worker in production:** `[env.production]` has no bindings, so production would run no purge.
